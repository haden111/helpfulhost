# Preview Project

Follow these steps to preview and test the application locally:

1. Ensure the development server is started:
   ```bash
   npm run dev
   ```

2. Open the browser to:
   [http://localhost:9002](http://localhost:9002)

3. Perform verification:
   - Check page load and render of logo and content.
   - Click navigation links (e.g., Front Door, Back Door).
   - Test language selector.
