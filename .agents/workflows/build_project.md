# Build Project

Follow these steps to build the application:

1. Install npm dependencies:
   ```bash
   npm install
   ```

2. Compile and typecheck:
   ```bash
   npm run typecheck
   ```

3. Build Next.js application:
   ```bash
   npm run build
   ```
