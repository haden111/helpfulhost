# **App Name**: Haden's Helpful Host

## Core Features:

- Welcome Page: Display a welcome message and language selection dropdown on the default index page.
- QR Code Navigation: Scan QR code to navigate to specific instructions pages based on location (e.g., front door).
- Auto-Language Detection: Automatically detect user's preferred language using browser settings or the visitor's IP address location lookup to choose a language.
- Manual Language Selection: Allow users to select their preferred language from a dropdown menu (23 languages supported) and save it in a cookie. This should over ride auto language setting..
- Text Translation: Translate instructional text to the user's selected language using AI translation tool. Fall back on Auto-language detection where selection doesn't exist.
- Content display: Display an image to the left or above with 1 or more text based instructions aligned on the right or underneath
- Friendly URL: The location code will be provided in the url.

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF) to create a welcoming and calming atmosphere, drawing inspiration from the hospitality concept.
- Background color: Very light gray (#F5F5F5) for a clean and unobtrusive backdrop.
- Accent color: Pale violet (#E6C5FF), used sparingly to draw attention to key interactive elements without overwhelming the user.
- Clean, sans-serif fonts such as Open Sans or Lato for easy readability across devices and languages.
- Simple, line-based icons to visually represent different instructions or points of interest. Consistency in style will ensure easy interpretation.
- Responsive grid layout to ensure optimal viewing on various screen sizes. Clear visual hierarchy with concise, easy-to-follow instructions.
